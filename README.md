# Signaleringsplan (werknaam)

Een heel simpele web-app voor cliënten met een licht verstandelijke beperking: een persoonlijk signaleringsplan met
drie stoplichtkleuren, grote tegels en geschetste plaatjes. Alles blijft op de telefoon.

- Wat de app doet: `docs/SPEC.md`
- Hoe we bouwen: `CLAUDE.md`
- Waar we staan: `docs/TASKS.md`

Werken met Claude Code: start met `/start-session`, sluit af met `/end-session`.
