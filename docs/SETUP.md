# Setup

Eenmalige stappen voor Sander. Claude Code helpt waar nodig; vraag het gerust als iets niet lukt.

## 1. Node.js controleren

Open Terminal en typ:

```bash
node -v
```

- Zie je `v20` of hoger (bijv. `v22.11.0`)? Klaar.
- Zie je een fout of een lager nummer? Installeer de **LTS-versie** van https://nodejs.org en probeer opnieuw.

## 2. GitHub-repo aanmaken

1. Ga naar https://github.com/new (ingelogd als TheBos24).
2. Naam: `signaleringsplan`. Kies **Public** (nodig voor gratis GitHub Pages) of Private als je een betaald
   GitHub-account hebt. De code bevat geen cliëntgegevens, dus Public is geen probleem.
3. **Niet** aanvinken: README, .gitignore of licentie (die maakt Claude).
4. Klik **Create repository**. Je ziet nu een lege pagina met een adres als
   `https://github.com/TheBos24/signaleringsplan.git`. Dat is goed.

## 3. Claude Code openen in deze map

Open Claude Code in de map `Documents/CLAUDE/Signaleringsplan` (zoals bij Polyp).

## 4. Eerste sessie starten

1. Kies het model van de eerste taak: **T-0.3 → Sonnet · medium** (via `/model`).
2. Typ `/start-session`.
3. Claude vertelt waar we staan en begint met de projectopzet.

## 5. Later: de app op je telefoon zetten (komt in T-0.4)

**iPhone (Safari):** open het adres dat Claude geeft → deelknop (vierkantje met pijl) → **Zet op beginscherm** → Voeg toe.
**Android (Chrome):** open het adres → menu (drie puntjes) → **App installeren** of **Toevoegen aan startscherm**.

Open de app daarna altijd via het icoon op je beginscherm, niet via Safari of Chrome (R-001).
